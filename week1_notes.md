\# Neural Networks – Key Takeaways



1\. A neural network is a function that maps inputs to outputs



2\. It has layers:

&#x20;  - Input layer (receives data)

&#x20;  - Hidden layers (process data)

&#x20;  - Output layer (produces result)



3\. Neurons have:

&#x20;  - Weights (how important is this connection?)

&#x20;  - Bias (shift the output)



4\. Activation functions add "non-linearity" (sigmoid, ReLU)
